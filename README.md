# 📂 Projects  

<h1 align="center"> 📈 PFB Yahoo Finance</h1>

Final bootcamp project that analyzes financial data from the top 100 Nasdaq 100 companies through data extraction, storage, processing, analysis, and visualization using Streamlit and Power BI. It includes machine learning models to create clusters and classify them based on price characteristics.

> **🏫 Project structure** 
- **Scraping and API usage**: Obtains the list of companies that make up the Nasdaq 100.
- **Data extraction**: Downloads historical price information and informational data for each company.
- **Processing**: Data cleaning and transformation.
- **Data storage**: Data modeling in MySQL.
- **Analysis**: The data is clustered and classified based on price characteristics.
- **Visualization**: Uses Streamlit to explore the data and Power BI report for deeper analysis.
